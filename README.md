# Killa — demo web

Versión estática y autónoma del prototipo de Killa.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `killa-demo`.
2. Sube a la raíz del repositorio los archivos `index.html` y `.nojekyll`.
3. Abre `Settings` → `Pages`.
4. En `Source`, elige `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/(root)`.
6. Pulsa `Save`.

GitHub mostrará la dirección pública cuando termine la publicación.

## Límites de esta versión

- No tiene cuentas de usuario ni base de datos remota.
- Guarda el progreso y el historial en el navegador mediante almacenamiento local.
- Si se borran los datos del navegador o se usa otro dispositivo, ese progreso no estará disponible.
- La meteorología depende de servicios externos y de que el navegador tenga conexión.
- No instala nada en el móvil: funciona como una web.
